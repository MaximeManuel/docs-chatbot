# Chatbot
An AI chatbot that provides answers based on PDFs and text documents. 

## Planned features
- Answer questions based on a PDF and text documents
- Claude LLM
- RAG pipeline with a vector database such as ChromaDB or Pinecone
- Provide accurate answers with document citations when possible
- Expose a simple API using Python and FastAPI
- Basic error handling and conversation history
- Setup and usage documentation
